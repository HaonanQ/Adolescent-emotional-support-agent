# 项目配置说明文档

## 📋 配置文件位置

所有配置文件位于 `src/main/resources/` 目录下：
- `application.yml` - 基础配置（已提交到git）
- `application-local.yml` - 本地开发环境配置（不会提交到git）
- `mcp-servers.json` - MCP服务器配置

---

## 🔧 必须配置项

### 1. MinIO 对象存储配置

**配置文件**: `src/main/resources/application-local.yml`

```yaml
minio:
  access-key: "minioadmin"        # MinIO访问密钥
  secret-key: "minioadmin"        # MinIO密钥
  end-point: "http://192.168.12.125:9000"  # MinIO服务地址
  bucket-name: "loveai-docs"      # 存储桶名称
```

**如何获取 MinIO 配置**：

1. **本地安装 MinIO**：
   ```bash
   # 使用 Docker 安装
   docker run -d \
     -p 9000:9000 \
     -p 9001:9001 \
     --name minio \
     -e "MINIO_ROOT_USER=minioadmin" \
     -e "MINIO_ROOT_PASSWORD=minioadmin" \
     minio/minio server /data --console-address ":9001"
   ```
   - 默认访问密钥：`minioadmin`
   - 默认密钥：`minioadmin`
   - 访问地址：http://localhost:9000
   - 控制台地址：http://localhost:9001

2. **使用云服务**：
   - 阿里云 OSS
   - 腾讯云 COS
   - AWS S3
   - 其他兼容 S3 的对象存储服务

3. **创建存储桶**：
   - 登录 MinIO 控制台
   - 创建名为 `loveai-docs` 的存储桶
   - 设置访问权限为 Public 或根据需要配置

---

### 2. Search API 密钥配置

**配置文件**: `src/main/resources/application-local.yml`

```yaml
search-api:
  api-key: "your-search-api-key-here"
```

**可选的搜索 API 服务**：

1. **Serper.dev**（推荐）：
   - 注册地址：https://serper.dev/
   - 免费额度：每月 2,500 次查询
   - 获取 API Key 后直接替换配置中的值

2. **Google Custom Search API**：
   - 需要创建 Google Cloud 项目
   - 启用 Custom Search API
   - 创建自定义搜索引擎
   - 获取 API Key

3. **Bing Search API**：
   - 注册 Azure 账号
   - 创建 Bing Search 资源
   - 获取 API Key

4. **其他搜索 API**：
   - Tavily API
   - DuckDuckGo API
   - 自建搜索服务

---

### 3. 阿里云 DashScope API 密钥

**配置文件**: `src/main/resources/application-local.yml`

```yaml
spring:
  ai:
    dashscope:
      api-key: "your-dashscope-api-key"
      chat:
        options:
          model: deepseek-v3.2
```

**如何获取 DashScope API Key**：

1. 访问阿里云百炼平台：https://bailian.console.aliyun.com/
2. 登录阿里云账号
3. 进入"API-KEY管理"
4. 创建新的 API-KEY
5. 复制 API-KEY 并替换到配置文件中

**支持的模型**：
- `deepseek-v3.2` - DeepSeek 模型
- `qwen-turbo` - 通义千问极速版
- `qwen-plus` - 通义千问增强版
- `qwen-max` - 通义千问旗舰版

## 📊 数据库配置

### MySQL

**配置文件**: `src/main/resources/application.yml`

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/loveai?useUnicode=true&characterEncoding=utf-8&serverTimezone=Asia/Shanghai
    username: root
    password: 123456
```

**初始化数据库**：
```bash
# 执行 SQL 脚本
mysql -u root -p < sql/create.sql
```

### PostgreSQL + PgVector

**配置文件**: `src/main/resources/application.yml`

```yaml
spring:
  datasource:
    url: jdbc:postgresql://localhost:5432/teen_emotion_rag
    username: postgres
    password: 123456
```

**安装 PgVector 扩展**：
```sql
-- 连接到 PostgreSQL 数据库
psql -U postgres -d teen_emotion_rag

-- 创建扩展
CREATE EXTENSION IF NOT EXISTS vector;
```

### MongoDB

**配置文件**: `src/main/resources/application.yml`

```yaml
spring:
  data:
    mongodb:
      uri: mongodb://root:root@192.168.12.125:27017/loveai
```

### Redis

**配置文件**: `src/main/resources/application.yml`

```yaml
spring:
  data:
    redis:
      host: localhost
      port: 6379
      password: 123456
```

## 🔐 安全建议

1. **永远不要将真实的 API 密钥提交到 git**
2. 使用 `.gitignore` 排除包含敏感信息的文件
3. 定期轮换 API 密钥
4. 为不同环境使用不同的配置文件
5. 生产环境使用环境变量或密钥管理服务

## ❓ 常见问题

### Q: MinIO 连接失败怎么办？
A: 检查 MinIO 服务是否启动，确认 end-point 地址是否正确，检查防火墙设置。

### Q: DashScope API 调用失败？
A: 确认 API Key 是否正确，检查账户余额，确认模型名称是否正确。

### Q: 数据库连接失败？
A: 确认数据库服务是否启动，检查用户名密码是否正确，检查网络连接。

### Q: 如何获取更多帮助？
A: 查看 `docs/` 目录下的文档，或联系项目维护者。
